== 实时演示（M15）的运行要点 ==
- dora 启动必须: source /home/dora/.venvs/dora-studio/bin/activate && dora up
  （不带 VIRTUAL_ENV 会用错 python；dora up 前台挂住属正常）
- cd examples/live-demo && dora start --name live-planning dataflow.yml
- 前端 Visualization: Live 模式 → 顶栏「实时数据」开 → Tools 挂 dviz-path
- Motion Planner: 目标 x/y/z → Plan（规划一次）→ Execute（机械臂运动）→
  Stop（回 home）→ Auto（轨道演示）；场景 + 添加箱子；模式 pill 指示
- 后端与前端各占 3001/5173；遗留进程占端口先查 ss -tlnp

（端口占用、dora 环境、数据流状态）、诚实性说明（哪些是合成演示数据、
哪些是真实计算、哪些标 unavailable）
