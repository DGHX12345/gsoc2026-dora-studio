== dora 运行要点（踩过的坑）==
- dora up 必须带 VIRTUAL_ENV，否则 daemon 用 `uv python find` 找到的 uv 托管
  python（无依赖）跑节点:
    source /home/dora/.venvs/dora-studio/bin/activate && dora up
  dora up 前台会挂住不退出，属正常，留它在后台跑
- dora start 会在数据流目录生成 out/dataflow-dora-session.yml 会话产物；
  Studio 后端扫描已跳过 out/ 目录（勿改回）
- dora stop 后立即 start 同名会报 "already a running dataflow"（名字释放有延迟），
  等 2-3 秒或用新名字
- dora logs 只能查运行中的 dataflow；`dora start --detach` 后台运行
