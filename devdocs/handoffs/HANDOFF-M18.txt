== 本次会话踩坑（新 AI 必读）==
- **dora 1.0 `dora list --format json` 是 JSON Lines**（每条记录一行
  独立对象，0 条=空输出，1 条=单对象）——session.rs 的 parse_list_entries
  与 coordinator.rs 的 parse_list_output 已三格式兼容（NDJSON/数组/单
  对象），新增解析代码时别假设数组
- **dora start 必须 stdin null**：继承终端 stdin 会进入 attach 模式挂住
  （runtime.rs build_start_command 已加，加新 spawn 时记得）
- **dataflows 发现用 CARGO_MANIFEST_DIR 优先**（workspace_root()），
  不依赖启动 cwd
- **cargo test 必须在无 coordinator/daemon 时跑**：metrics 测试 spawn
  真实 dora，环境不匹配会假失败；且 metrics 的 CLI 测试现在持
  TEST_ENV_LOCK（dora_env.rs 里），所有改 DORA_STUDIO_DORA_BIN 或
  settings 的测试必须用这把锁
- 测试残留进程要清理（dora down + kill 后端），否则下次 cargo test 失败
- 前端 tools 测试是 tsx/node 环境（无 DOM），纯函数放 session-ui.ts
  之类的独立模块；样式只用主题 token（--text-*/--bg-*/--card-*/
  --hairline/--accent-*），禁 --col-*；正文 ≥12px
